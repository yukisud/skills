# デザインレビュースキル(日本市場基準)

制作物(バナー・LP・スライド・UI)を出稿・公開前にレビューする。作った本人(または生成した自分)以外の目として機能させるため、**制作とレビューは別セッション/別エージェントで行う**(`management/agent-team-orchestration-ja` の原則)。

## レビューの進め方

1. 制作物の**目的とターゲット**を確認する(不明なら差し戻し。目的のないデザインは評価不能)
2. 下記観点でチェックし、指摘には必ず「箇所+理由+修正案」を付ける
3. 判定: 承認 / 条件付き承認(軽微修正) / 差し戻し(目的不達成・法令リスク)

## 観点1: 伝達(最重要)

- [ ] **3秒テスト**: 初見3秒で「誰向けの・何の・どうしてほしい」が伝わるか。バナーは1秒
- [ ] 情報の優先順位がサイズ・太さ・色のジャンプ率で表現されているか(全部強調=全部弱い)
- [ ] 視線の流れが自然か(日本語横組みはZ型/F型。CTAが流れの終点にあるか)
- [ ] 1つの制作物に主張が1つか(訴求の詰め込みを検出したら分割を提案)
- [ ] キャッチコピーが画像を見なくても成立し、画像がコピーを補強しているか(画像とコピーが別のことを言っていないか)

## 観点2: 造形

- [ ] 余白: 要素間の余白が関係の近さと一致しているか(近接の原則)。端の余白が均等か
- [ ] 整列: 揃えの基準線が混在していないか(左揃え・中央揃えの無計画な混在)
- [ ] 配色: ベース70/メイン25/アクセント5の比率目安。アクセント色がCTA専用になっているか(装飾に浪費していないか)
- [ ] トンマナ: ブランド・媒体の他の制作物と一貫しているか
- [ ] 写真・イラストの品質: 引き伸ばしボケ、不自然な生成AI画像の破綻(手指・文字・背景)、被写体の目線とCTAの位置関係

## 観点3: 日本語タイポグラフィ

`engineering/frontend-design-ja` の数値基準を適用する。レビューでの頻出指摘:
- [ ] 行間の詰まりすぎ(日本語本文はline-height 1.7目安、バナー内でも1.3以上)
- [ ] 約物の処理: 行頭の句読点・閉じ括弧、連続する記号の字面調整
- [ ] 長体・平体の乱用(文字を潰して詰め込んでいたら情報量の削減を提案)
- [ ] 和文フォントの混在(1制作物で和文2書体まで)
- [ ] 全角半角の不統一(数字・英字)

## 観点4: 可読性・アクセシビリティ

- [ ] 文字と背景のコントラスト比4.5:1以上(写真上の白文字は座布団・グラデーションで担保)
- [ ] スマホ実寸での文字サイズ(バナーはフィード縮小表示で読めるか)
- [ ] 色だけに依存した情報伝達がないか(グラフ・必須マーク)

## 観点5: 法令・規定の視認性(日本固有)

- [ ] **打消し表示**: 注記(※適用条件等)が本文の主張と同一視野・十分な文字サイズ・コントラストで読めるか(小さいグレー6ptの注記は景表法上の違反リスク)
- [ ] No.1・受賞表示に出典(調査機関・範囲・時期)が併記されているか
- [ ] 医療: ビフォーアフター写真・体験談風の構図が使われていないか(`creative/ad-creative-ja` §5)
- [ ] 価格表示: 税込が主表記か。二重価格の根拠表記
- [ ] ロゴ・素材の権利表記、媒体ロゴのレギュレーション(公式ロゴの改変禁止等)

## 出力フォーマット

```
## デザインレビュー: (制作物名)
### 判定: 承認 / 条件付き承認 / 差し戻し

### 目的への適合(3秒テストの結果)
(初見で何が伝わったかを先入観なしに記述)

### 指摘事項
| # | 重要度 | 箇所 | 指摘 | 修正案 |
(重要度: 必須=法令・目的不達成 / 推奨 / 好み)

### 良い点(1〜3個。維持すべき判断を明示)
```

## 原則

- 「好み」の指摘を「必須」に混ぜない。重要度を必ず分離する(デザイナーとの信頼関係を守る)。
- 差し戻しは2回まで。2回で解決しない齟齬は指示書(`creative/ad-creative-ja` の制作指示書)側の欠陥を疑い、指示書を直す。
- レビューで承認したものは承認者として記録に残る意識で判定する(「なんとなくOK」を出さない)。
