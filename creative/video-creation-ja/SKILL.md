# 動画制作スキル(マーケ・SNS向け)

短尺動画を「企画→台本→絵コンテ→素材指示→編集→書き出し」の工程として設計する。実際のレンダリングは接続した動画生成/編集ツール(要 `engineering/connection-setup-ja`)で行い、接続がなければ台本・絵コンテ・素材指示書までを納品する。静止画・サムネは `creative/image-generation-ja`、配信は `marketing/sns-organic-ja`、広告としての訴求・法令は `creative/ad-creative-ja` と連携。

## 0. 企画(作り始める前に)

- **1動画1メッセージ・1CTA**。目的(認知/理解/行動)とKPIを先に決める(`sns-organic-ja` の型の配合に載る)
- ターゲットの視聴状況(音声オン/オフ、フィード流し見か検索視聴か)。**日本のSNSは音声オフ視聴が多数**→字幕前提で設計
- 訴求は `gtm/positioning-messaging-ja` の主訴求から。動画単体で新しい訴求を発明しない

## 1. 構成台本(尺と型)

- **最初の1〜2秒で「誰向け・何の得か」を提示**(ロゴやオープニングから始めない。スキップ・スワイプされる)
- 型の例: フック(問題提起)→ 結論先出し → 根拠/手順 → CTA。解説系は「結論→理由→具体例→まとめ」
- 台本はカット単位で書く(下記フォーマット)。1カット=1情報、テンポは短尺ほど速く

## 2. 媒体別の尺・仕様(2026年時点・要 `connection-setup-ja` 台帳で最新確認)

| 媒体 | 比率 | 尺の目安 | 注意 |
|---|---|---|---|
| TikTok / Reels / Shorts | 9:16 | 15〜60秒 | 上下UIのセーフゾーン(上約14%・下約20%)を空ける。冒頭2秒が命 |
| YouTube(通常) | 16:9 | 目的次第 | サムネ+タイトルで視聴が決まる(サムネは image-generation-ja) |
| X 動画 | 16:9 or 1:1 | 〜140秒目安 | 自動再生・音声オフ前提、字幕必須 |
| 広告(インストリーム) | 媒体依存 | 6秒/15秒 | 6秒バンパーは1メッセージのみ。`ad-creative-ja` の審査・法令チェックを通す |

- 字幕は全カットに(音声オフ対応+アクセシビリティ)。フォント・行長は `frontend-design-ja` の日本語タイポ基準
- 縦動画は1画面の情報量を絞る(スマホ実寸で読める文字サイズ)

## 3. 素材の指示

- **映像**: 実写素材/生成映像/スライド録画のどれか。生成する場合は `image-generation-ja` の仕様化(Scene/Subject/Details/Constraints)を各カットに適用。権利(実在人物・楽曲・既存映像)を必ず確認
- **ナレーション**: 原稿+読み速度+トーン。合成音声を使う場合は不自然な区切りを台本側で調整
- **BGM/効果音**: 商用利用可のライセンス素材のみ。medium音量でナレーションを邪魔しない
- **字幕・テロップ**: 話し言葉のまま載せず要点を短く。強調箇所の色・出し方を指定

## 4. 制作進行と工程

```
企画確定 → 台本 → 絵コンテ(カットごとの画・字幕・音)→ 素材準備 →
仮編集 → レビュー(creative/design-review-ja)→ 修正 → 書き出し → 配信(sns-organic-ja)
```

- レンダリングは接続ツールに投げる。長時間処理はバックグラウンド化し、完成物のパスを納品
- 書き出し設定: 媒体推奨のコーデック・解像度・ファイルサイズ上限を守る(媒体側の再圧縮で劣化するため過度な高ビットレートは無駄)

## 5. 出力様式(台本・絵コンテ)

```
## 動画企画: (タイトル)
- 目的/KPI / ターゲットと視聴状況 / 媒体・尺・比率 / 主訴求 / CTA

## 絵コンテ
| # | 時間 | 画(映像指示) | ナレーション | 字幕/テロップ | 音 |
|---|------|------------|------------|-------------|----|

## 素材リスト(権利確認欄つき)
| 素材 | 種類 | 入手/生成方法 | 商用利用可否 |

## 書き出し仕様と配信先
```

## 6. 法令・権利チェック(公開前)

- [ ] 楽曲・効果音・フォント・映像素材の商用ライセンス
- [ ] 実在人物の肖像・声、既存キャラ・ブランドの無断使用がないか
- [ ] 広告動画なら景表法・医療広告GL・薬機法・ステマ規制(`ad-creative-ja` §5と同基準)
- [ ] 字幕・テロップの誤情報・誤字(拡散後の訂正は追いつかない)

## 原則

- 尺を埋めるための水増しをしない(短く言い切る)。1本の完成度より、`sns-organic-ja` の月次サイクルで「型×反応」を回して勝ち構成を見つける方を優先
- 派手な編集技巧よりメッセージの明快さ。過剰なトランジション・エフェクトはAI/テンプレ感を増やす(`frontend-design-ja` の過剰アニメ抑制と同じ)
