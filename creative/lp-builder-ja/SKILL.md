# LP構築スキル(日本仕様)

広告の受け皿となるLPを、構成→原稿→実装指示→計測設計まで一気通貫で作る。実装のデザイン品質は `engineering/frontend-design-ja`、広告との整合は `marketing/google-ads-ja-ops` と連携。

## 0. 着手前の確認

- 流入元(検索広告/SNS広告/自然検索)と流入KW・クリエイティブ。**広告の訴求とLPファーストビューのメッセージ一致(メッセージマッチ)がCVR最大の変数**。
- CVポイント(電話/フォーム/LINE/予約システム)と現状CVR。
- 業種の規制(医療・薬機法・金融)。

## 1. セクション構成の定石(日本のリード獲得型LP)

```
1. ファーストビュー: キャッチコピー(検索KWと呼応)+権威・実績の要素+CTA+ビジュアル
2. 共感: 「こんなお悩みありませんか」(3〜5個。ターゲットの言葉で)
3. 解決の提示: 商品・サービスが悩みをどう解決するか
4. 選ばれる理由: 3〜4点。**形容詞でなく事実で**(「丁寧な対応」× →「初回カウンセリング60分」○)
5. 証拠: 実績数値・事例・資格・設備(医療は体験談・ビフォーアフター制限に注意)
6. 流れ: 申込みから利用までのステップ(日本のユーザーは事前に全体像を知りたがる。来店型では特に効く)
7. 料金: 隠さない。税込表示(総額表示義務)。医療自由診療は限定解除3要件とセット
8. FAQ: 反論処理(高い/怖い/時間がない への回答)
9. クロージングCTA+アクセス情報(来店型は地図・駅からの経路・駐車場)
```

- CTAはファーストビュー・中間(証拠の後)・最下部の最低3箇所。文言は「送信」ではなく行動の結果がわかるもの(「無料相談を予約する」「30秒で資料請求」)。
- モバイル: 固定フッターCTA(来店型は `tel:` リンク併設)。**流入の7〜8割はスマホ**である前提でスマホ版を先に設計する。

## 2. EFO(フォーム最適化)チェックリスト

- [ ] 項目数は最小(リード獲得なら4項目以内から開始)。「必須」バッジを全項目に付けるくらいなら項目を削る
- [ ] 確認画面は原則廃止(1画面完結+送信後サンクスページ)。慣習で残す場合はA/Bテスト対象に
- [ ] `inputmode`・`autocomplete` 設定、郵便番号→住所自動入力、フリガナ自動入力
- [ ] エラーはリアルタイム表示・日本語で修正方法まで示す(「全角カタカナで入力してください」)
- [ ] プライバシーポリシー同意はリンク+チェック1つ。メルマガ同意を混ぜ込まない(`marketing/hubspot-ops-ja` の法令要件参照)
- [ ] 送信ボタン近くに安心要素(「営業電話はいたしません」等、事実である場合のみ)

## 3. 法定表記・コンプライアンス

| 業種・形態 | 必須事項 |
|---|---|
| EC・通販 | 特定商取引法に基づく表記(事業者名・住所・電話・返品条件)。定期購入は最終確認画面に総額・回数条件を明示 |
| 医療(歯科含む) | 自由診療の限定解除3要件(問い合わせ先/治療内容・費用/リスク・副作用)。体験談・誤認ビフォーアフター禁止。「最新」「無痛」等の表現チェック |
| 全業種 | 総額表示(税込)、景表法(No.1表記の根拠・打消し表示の視認性)、プライバシーポリシー |

該当業種のLPを出力する際は、このチェックを通した結果を成果物に添える。

## 4. 計測設計(公開前に必須)

- CVタグ: フォーム送信完了(サンクスページorイベント)、電話タップ、LINE友だち追加をそれぞれ別CVとして定義。
- タグはGoogleタグマネージャー(GTM ※Tag Managerの方)経由で設置し、プレビューで発火確認してから公開。
- 広告からの流入はURLパラメータを保持したままフォームのhiddenに渡す(`marketing/hubspot-ops-ja` 連携)。
- ヒートマップ/スクロール計測を初月だけでも入れ、改善はデータで判断する。

## 5. 公開後の改善ループ

1. 计測データで離脱点を特定(FV直帰/フォーム到達率/フォーム完了率に分解)
2. 仮説→**1変数ずつ**テスト(FVコピー→CTA→フォームの優先順)
3. 判定は十分なサンプルで(目安: 各案100CV未満で微差の勝敗判定をしない。少CVならFV直帰率など中間指標で判断)

## 出力様式

構成案は「セクション/目的/見出し案/ボディ原稿/ビジュアル指示」の表で出す。実装まで行う場合は `frontend-design-ja` の品質チェックリストを通した上で、計測タグの設置箇所リストを添付する。
