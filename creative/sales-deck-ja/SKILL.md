# 資料作成スキル(日本のビジネス文書仕様)

そのまま清書・スライド化できる資料の構成と原稿を作る。デザイン面は `engineering/frontend-design-ja` のタイポグラフィ基準、文体仕上げは `marketing/ja-humanizer` と連携。

## 大前提: 日本の提案資料は「回覧される」

プレゼンの場にいない決裁者が、**説明なしで読んで判断できる**資料にする。これが欧米式ピッチデッキとの最大の違い。
- スライドタイトルは体言止めのラベル(「市場環境」)ではなく、**結論を文で書くメッセージライン**にする(「問い合わせの3割が営業時間外に発生しており、機会損失が月◯件」)。タイトルだけ拾い読みして論旨が通ることを完成条件とする。
- 口頭で補足する前提の「あえて余白のあるスライド」を作らない。ただし詰め込みは分割で解決する(1スライド1メッセージ)。

## 提案書の標準構成

```
1. 表紙(宛名「◯◯株式会社 御中」・提案タイトル・日付・社名)
2. エグゼクティブサマリ(1枚: 課題→提案→効果→費用→スケジュールを5行で)
3. 現状の整理(相手から聞いた事実。ここで「わかってる感」を作る)
4. 課題の構造化(事実→なぜ起きるか→放置するとどうなるか)
5. 提案内容(課題と1対1で対応させる。課題に紐付かない提案項目は削る)
6. 効果試算(前提を明記した計算式。下記ルール)
7. 進め方(スケジュール・体制・双方の役割分担)
8. 費用(税込/税抜を明記。松竹梅の3案が日本では通りやすい)
9. 次のステップ(相手に取ってほしい行動を1つに絞って明記)
付録: 会社概要・実績・FAQ
```

- 決裁者向けにはサマリで完結、実務者向けには本編で納得、という2層で設計する。
- **効果試算のルール**: 計算式と前提(CVR等の仮置き値と根拠)を必ず紙面に書く。良いケースだけ見せず、保守/標準の2ケース併記。試算根拠を書かない「売上◯%アップ!」は信頼を落とす。

## その他の資料タイプ

| タイプ | 構成の要点 |
|---|---|
| セミナー資料 | 冒頭で「持ち帰れること」を宣言→本編→まとめ1枚→CTA(個別相談)。1スライド90秒目安で枚数を決める |
| ホワイトペーパー | 表紙のタイトルがDL率を決める(数字+ベネフィット)。中身は事例と手順で構成し、自社宣伝は最終章のみ |
| 社内報告・稟議書 | 結論→理由→データ→リスクと対策→承認してほしい事項。A4一枚に収める文化圏が多い |

## デザインシステムの分離(SLIDE.md方式)

スライドの見た目のルールを資料ごとに考え直さない。**デザイン定義(SLIDE.md)と内容(スライド原稿)を分離**し、同じ定義から全資料を量産する:

1. `SLIDE.md` を一度作る: 配色(ブランドカラー+強調1色)、フォント(和文/英数)、余白、表紙・中扉・本文・図表ページの型、ロゴ配置。既存の良い資料やブランドガイドがあれば、そこから色・フォント・構図を抽出して定義する
2. 資料作成時は「SLIDE.mdに従って+スライド原稿」の2点をレンダリング工程(スライド生成ツール・pptx化)へ渡す
3. トーンの変更はSLIDE.mdを直して全資料へ反映(資料単位で色をいじらない)

クライアントごとに別ブランドで出す場合は `SLIDE-<クライアント名>.md` を分けて管理する。グラフの描き方は `data-science/dashboard-design-ja` の規律(構成比は横棒・軸0起点・タイトルに期間と単位)に従う。

## スライド原稿の出力フォーマット

```
### スライドN
- メッセージライン: (結論の一文)
- ボディ: (箇条書き or 図表の指定)
- 図表指定: (種類・軸・強調箇所。dashboard-design-ja の規律で)
- 備考: (口頭補足・アニメーション等)
```

## 品質チェックリスト

- [ ] メッセージラインだけ通読して論旨が通る
- [ ] 1スライドに主張が2つ以上入っていない
- [ ] 数字に出典・前提が付いている(社内データ/公的統計/仮置きの別を明記)
- [ ] 効果試算が計算式ごと紙面に載っている
- [ ] 「次のステップ」が相手の具体的行動1つになっている
- [ ] 宛名・敬称(御中/様)・日付・自社連絡先が正しい
- [ ] 競合比較を載せる場合、出典のある事実比較になっている(主観の◯△×表は景表法・信義上のリスク)
- [ ] 医療・規制業種の実績紹介で症例写真・体験談の扱いが適法か

## 文章ルール

- 資料内の文体は「だ・である」または体言止めで統一(メール・送付状は「です・ます」)。
- 1行の文字数はスライドで全角30字以内目安。3行を超える段落は分割か図解化。
- 英数字は半角、単位・年号は「2026年」「◯万円」で統一。金額の税込/税抜は初出で明記。
