# 広告クリエイティブ制作スキル(日本仕様)

バナー・動画・SNS広告のコンセプト設計から制作指示書までを作る。コピーの親は `gtm/positioning-messaging-ja` のメッセージングフレームワーク、検索広告文は `marketing/rsa-copywriter-ja`、出稿判断は `marketing/google-ads-ja-ops` が担当。

## 1. 企画: 訴求軸マトリクス

クリエイティブは単発で作らず、**訴求軸×フォーマットのマトリクス**で計画する:

```
| 訴求軸 \ フォーマット | 静止画1:1 | 静止画9:16 | 動画15s | カルーセル |
| 主訴求(例: 費用明示) | 案A | … | | |
| 不安解消(例: 痛み・失敗) | 案B | | | |
| 社会的証明(例: 症例数) | | | | |
```

- 1回のテストで検証する訴求軸は2〜3。**同一訴求軸内のデザイン違いより、訴求軸違いの方が成果差が大きい**ので軸から試す。
- 各案に「ターゲットの状態(顕在/潜在)」を明記。潜在層向けに商品名を叫ぶだけのバナーを作らない。

## 2. 日本で機能しやすい型(仮説の初期値)

| 型 | 向き | 注意 |
|---|---|---|
| 漫画・イラスト導入 | 潜在層・悩み系 | 1コマ目=ターゲットの状況描写。オチで解決を見せる |
| 費用・料金明示型 | 比較検討層 | 税込表示。医療自由診療はLP側の限定解除とセット |
| お客様の声・UGC風 | BtoC全般 | **医療は体験談広告が禁止**。一般業種も「広告」であることの明示(ステマ規制: 事業者が関与した投稿風広告はNG) |
| 権威・実績数字型 | 高関与商材 | 数字の根拠必須(景表法)。「No.1」は調査出典・範囲・時期を画像内に |
| ビフォーアフター | 美容・リフォーム等 | **医療・歯科は原則不可**(誤認防止の詳細説明があっても広告では高リスク)。薬機法対象も効能保証表現になりやすい |
| 締切・オファー型 | 刈り取り | 「今だけ」に実態がないと有利誤認。恒常的な「毎月先着◯名」は炎上リスク |

## 3. 媒体別入稿規格(2025年時点の主要どころ)

| 媒体 | 推奨サイズ | テキスト・時間の目安 |
|---|---|---|
| Meta(FB/IG フィード) | 1080×1080(1:1)、1080×1350(4:5) | 画像内テキストは少なめが原則。メインテキスト125字/見出し40字以内で切れずに表示 |
| Meta(リール/ストーリーズ) | 1080×1920(9:16) | 上下にUIが被るためセーフゾーン(上約14%・下約20%)を空ける |
| LINE広告 | 1200×628、1080×1080、小画像1200×628相当 | タイトル20字・ディスクリプション75字。LINE面はファミリー層まで広いためトーンは万人向けに |
| YouTube | バンパー6秒、スキッパブル15〜30秒 | **冒頭2秒で誰向けかを明示**(スキップ前に指名)。音無しでも伝わる字幕必須 |
| GDNレスポンシブ | 1200×628(1.91:1)、1200×1200(1:1)、ロゴ | 短い見出し全角15字・説明文全角45字(RSAと同じカウント) |
| Yahoo!ディスプレイ(YDA) | 1200×628、1080×1080 | ニュース面掲出。過度な扇動表現は審査落ちしやすい |

- 動画は**最初の3秒**に(1)ターゲット呼びかけ (2)ベネフィット提示のどちらかを置く。ロゴから始めない。
- スマホ表示前提で、画像内文字は最小でも全体の高さの1/15以上のサイズに。

## 4. 制作指示書フォーマット(デザイナー/生成AIへの発注)

```
## クリエイティブ指示書: (案件名_訴求軸_サイズ)
- 目的とKPI: (例: Meta潜在層でCPA◯円以内のCV獲得)
- ターゲットと状態: (誰が・どんな瞬間に見るか)
- メインコピー: (画像内に載せる全文字。文字数と優先順位)
- ビジュアル指示: (構図・被写体・トーン。参考URLがあれば)
- 必須要素: (ロゴ・法定表記・打消し表示の内容と最低サイズ)
- NG: (法令NG表現・ブランドNG・媒体規定)
- サイズ展開: (上表から)
- 納品形式: (px、ファイル形式、容量上限)
```

## 5. 法令・審査チェック(出稿前必須)

- [ ] 医療: 体験談・ビフォーアフター・「無痛」「最新」等の禁止/要注意表現(詳細は `marketing/google-ads-ja-ops` §5)
- [ ] 景表法: No.1・最上級表現の根拠、二重価格、**打消し表示が本文と同等に視認できるか**(小さすぎる注記は違反)
- [ ] 薬機法対象: 効能効果の逸脱、使用前後写真
- [ ] ステマ規制: タイアップ・UGC風には「広告」「PR」の明示
- [ ] 媒体審査: 個人の身体的特徴への言及(Meta)、過度な扇動・コンプレックス刺激表現(各媒体共通で審査落ち+ブランド毀損)
- [ ] 素材の権利: ストック写真のライセンス範囲、人物モデルリリース、フォントの商用利用可否

## 6. テストと疲弊管理

- テストは**1変数ずつ**(訴求軸→ビジュアル→コピーの順)。判定は各案おおむね50CV or 統計的有意まで、少額運用ならCTR・CVRの中間指標で早期判断。
- 疲弊監視: フリークエンシー3〜4超過またはCTRがピーク比30%低下したら差し替え。**勝ちクリエイティブの「同型変奏」を常に2本ストック**しておく。
- 結果は「訴求軸×成果」で記録し、メッセージングフレームワーク(`gtm/positioning-messaging-ja`)に学びを還元する。
