# ビジネスメール作成スキル(日本語)

そのまま送れる品質のメールを作る。過剰な定型で長くなりすぎず、失礼にもならないバランスを取る。

## 基本フォーマット

```
件名: 【◯◯】用件が一目でわかる具体的な件名(全角20字以内目安)

◯◯株式会社
◯◯部 ◯◯様          ← 社名は正式名称(「(株)」略記はしない)。部署・役職があれば入れる

いつもお世話になっております。◯◯の◯◯です。   ← 初回は「初めてご連絡いたします」等

(用件の結論を最初の2〜3行で)

(詳細・背景・選択肢)

(相手にしてほしいこと+期日)

お忙しいところ恐れ入りますが、◯月◯日(◯)までにご返信いただけますと幸いです。
今後ともよろしくお願いいたします。

―――
署名(社名/氏名/電話/メール)
```

- **件名で用件が完結する**こと(【ご相談】【日程調整】【御礼】等の接頭辞+具体)。「お世話になっております」だけの件名は禁止。
- 結論先出し。経緯から書き始めない(スマホで最初の3行しか見えない前提)。
- 依頼には必ず期日と、相手のアクションを1つに絞って書く(「ご検討ください」で終わらせず「AかBかご指定ください」)。
- 1メール1用件が原則。複数ある場合は箇条書きで番号を振り、返信しやすくする。

## 敬語チェック(添削時の頻出指摘)

| NG | OK | 理由 |
|---|---|---|
| ご確認させていただきます | 確認いたします | 「させていただく」は相手の許可・恩恵がある場合のみ。乱用は冗長 |
| お伺いさせていただきます | 伺います | 二重敬語 |
| ◯◯様が申されました | ◯◯様がおっしゃいました | 「申す」は謙譲語 |
| 御社(メール文中) | 貴社 | 「御社」は話し言葉、書き言葉は「貴社」(病院は「貴院」) |
| 了解しました(目上へ) | 承知いたしました | 慣用上の配慮 |
| ご苦労さまです(目上へ) | お疲れさまです/お世話になっております | 「ご苦労さま」は目下向け |
| とんでもございません | とんでもないことでございます(または「恐れ入ります」) | 厳密には誤用だが許容が進む。無難な代替を提案 |

- 敬語の過剰積み増し(「ご査収いただけますと幸いに存じ上げます」)は読みにくさで失礼になる。**丁寧さは敬語の量でなく、相手の手間を減らす構成で出す。**

## 用件別の型

### 依頼
クッション(お忙しいところ恐れ入りますが)→依頼内容→理由→期日→相手の負担への配慮。無理な期日の場合は理由と代替案を添える。

### 催促(角を立てない)
1回目: 「行き違いでしたら失礼いたします」+再送+期日再提示。
2回目: 影響を事実で伝える(「◯日までにいただけない場合、公開が◯日遅れます」)+電話等の代替手段の提案。
**責める表現(「まだですか」「お忙しいとは思いますが」の嫌味的使用)を使わない。**

### 謝罪
事実の認定→謝罪→原因→対応(済みのこと)→再発防止→改めて謝罪。言い訳を謝罪より先に書かない。「ご迷惑をおかけしましたこと、深くお詫び申し上げます」。重大案件はメールで完結させず電話・訪問の意向を添える。

### 断り
感謝→結論(お受けできない)→理由(差し支えない範囲で具体的に)→代替案 or 将来への含み。曖昧に濁して相手を待たせるのが最も失礼。

### 日程調整
候補を3つ、幅を持たせて提示(「◯日(火)10:00〜12:00の間」)。相手の指定を優先する一文を添える。決定後は日時・場所・URL・所要時間を確定メールで再掲。

## 送信前チェック

- [ ] 宛名の社名・氏名・敬称(様/御中の使い分け。人名+御中はNG)
- [ ] 添付の付け忘れ・パスワード運用(会社ルールに従う)
- [ ] To/Cc/Bccの適切さ(**社外一斉送信のBcc漏れは個人情報漏えい事故**)
- [ ] 期日・金額・固有名詞の再確認
- [ ] 返信の場合: 引用の残しすぎを整理、件名のRe:は保持(勝手に変えない)
- [ ] 特定電子メール法: 営業目的の新規メールは同意・取引関係等の根拠があるか、配信停止手段の記載(一斉配信の場合は `marketing/hubspot-ops-ja` の要件を参照)
