# 品質監査レポート(2026年7月)

全スキルを対象に実施した実務品質監査の記録。次回監査時はこのファイルを更新する。

## 監査基準(6項目)

| # | 基準 | 判定方法 |
|---|---|---|
| 1 | 起動条件がdescriptionに明確か | frontmatter検査(機械) |
| 2 | 入力(何を渡すか)の定義があるか | 本文検査(機械+目視) |
| 3 | 手順に数値基準があるか(抽象論で終わっていないか) | 目視 |
| 4 | 出力・納品物の形式が定義されているか | 見出し検査(機械)+目視 |
| 5 | スキル間の参照先が実在するか | パス検査(機械) |
| 6 | 事実(法令・媒体仕様・文字数)が正確か | 目視・根拠照合 |

## 実施結果

- 基準1・2・5: **全スキル合格**(機械検査)
- 基準4: 9件の検出のうち5件は誤検知(出力形式が別見出しで存在)。実欠落4件を修正済み(systematic-debugging / sns-organic / line-official / press-release に出力様式を追加)
- 基準6: 過去の監査で発見・修正した誤り(再発注意):
  - 医療広告の限定解除を「3要件」と誤記 → 正式4要件+広告文自体には適用されない旨を明記
  - 総額表示で「10,000円(税込11,000円)」を不可と誤記 → 適法(不可は税込総額のない表示)
  - RSA見出しの感嘆符を「1個まで」と誤記 → 見出しは使用不可、説明文1個まで
  - 個人情報漏えい報告基準「1,000件超」→「1,000人分超」

## 既知の限界(利用時の前提)

- 数値基準(CV件数のしきい値、ブロック率30%等)は**業界横断の経験則**。自社実績が貯まったらスキル本文を実測値で上書きすること(スキルは育てる資産)。
- 法令記述は実務チェックリストであり法的助言ではない。判断が割れる案件は専門家(弁護士・行政書士・薬機法専門家)へ。
- 同梱スクリプト(remove_chroma_key.py / log-tool-use.sh)は動作検証済みだが、環境依存(Pillow・jqの有無)は各READMEどおり。

## 次回監査時のチェックコマンド

```bash
# frontmatter・参照・構造の一括検査
for f in */*/SKILL.md; do dir=$(basename $(dirname $f)); name=$(sed -n 's/^name: //p' "$f" | head -1); [ "$name" != "$dir" ] && echo "NG: $f"; done
grep -rhoE '`(gtm|marketing|creative|engineering|management|data-science)/[a-z-]+`' --include="SKILL.md" . | sort -u | tr -d '`' | while read ref; do [ -d "$ref" ] || echo "NG参照: $ref"; done
```
