# スキル監査記録: trailofbits/skills(2026-07)

## 判定: 導入推奨(プラグイン直接導入・日本語での作り直しはしない)

## 対象
- リポジトリ: https://github.com/trailofbits/skills(⭐6.8k、CC-BY-SA 4.0)
- 作者: **Trail of Bits**(世界トップクラスのセキュリティ監査企業)
- 形式: Claude Code プラグインマーケットプレイス、52スキル
- 用途: **全て防御**(監査・脆弱性検出・コードレビュー・検証)。攻撃自動化なし

## 内容の要約
コード監査(C/Rust/Semgrep/CodeQL/SARIF)、暗号検証(constant-time/zeroize)、
サプライチェーン監査、スマートコントラクト、YARA、プロパティベーステスト、
Lean 4証明、モバイル(APK)など高度に技術的・ツール特化。

## なぜ日本語で作り直さないか
- 内容が**言語・ツール特化で日本固有の観点がない**(Rustのメモリ安全バグは日本でも同じ)。
  当リポジトリの価値=日本の商習慣・法令の付与が、この技術監査には効かない
- 専門性が極めて高く、再著述は価値を足さず誤りを持ち込むリスクの方が大きい
- Claude Codeプラグイン形式でそのまま使え、会話が日本語なら出力も日本語になる

## 統合方法(作り直しでなく橋渡し)
- `engineering/security-review-ja` に「深い技術監査への委譲」節を追加し、
  差分の性質→委譲先スキルの対応表と導入コマンドを記載
- 当リポジトリの `security-review-ja` = 広く浅い一次レビュー+日本の法令、
  trailofbits/skills = 深い技術監査、という役割分担を明確化

## 導入手順
```
/plugin marketplace add trailofbits/skills
/plugin menu   # 必要なスキルのみ有効化
```
CC-BY-SAのため、当リポジトリのMarkdownへ本文を転記する場合は帰属・継承ライセンス表示が必要。
→ 転記せず「委譲先として参照」に留めることでライセンス上も安全。

## 再監査条件
プラグイン更新時は Trail of Bits の変更履歴を確認(信頼できる発行元だが習慣として)。
