# Google広告 日本市場運用スキル

日本のアカウント運用を前提とした判断ロジック。数値はすべて円建て・税抜で扱い、レポートや提案に出す際は税込/税抜を必ず明記する。

## 0. 運用判断の前提確認

分析・提案の前に必ず以下を把握する。不明ならユーザーに確認するか、データから推定して推定である旨を明記する。

- ビジネスモデル: リード獲得型(店舗・士業・BtoB)か、EC型か、アプリ型か
- 目標CPA / 目標ROAS と、その根拠(LTV・粗利)
- 規制業種か: **医療(歯科含む)・薬機法対象・金融・人材は日本固有の規制あり**(下記5章)
- 計測基盤: コンバージョン定義、電話CV・来店/来院CVの計測有無、オフラインCVインポートの有無

## 1. アカウント構成の原則(2025年以降の日本市場)

- Hagakure型のシンプル構成を基本とし、**インテント(顕在/比較/潜在)× ブランド/一般** で分ける。
- ブランドKWは必ず専用キャンペーンに分離。日本ではブランド指名の変換効率が極端に高く、混ぜると一般KWの実力が見えなくなる。
- ローカルビジネス(店舗・教室・クリニックなど)は「地域名 × サービス名」(例: 「渋谷 パーソナルジム」)を軸に、**半径ターゲティングより市区町村指定を優先**(日本は通勤圏行動が広く、半径指定は通過交通を拾いやすい)。
- マッチタイプ: インテントマッチ(旧・部分一致)+スマート自動入札の組み合わせを基本としつつ、**日本語は同音異義語・表記ゆれで無関係クエリを拾いやすい**ため、除外KW運用(negative-keyword-scanner)を週次で必須とする。

## 2. 入札・予算の判断ロジック

| 状況 | 判断 |
|---|---|
| CV月30件未満 | クリック数最大化 or 個別クリック単価で学習データを貯める。tCPAはまだ入れない |
| CV月30〜50件 | コンバージョン数最大化(目標値なし)へ移行 |
| CV月50件以上 | tCPA/tROAS導入。目標値は直近30日実績CPAの±20%以内から開始 |
| 学習期間中(変更後1〜2週) | 大きな変更を重ねない。日予算変更は±20%/回まで |
| インプレッションシェア損失(予算)>20% | 予算増額を提案。損失(ランク)>40%なら品質・入札の改善を先に |

- 日本の祝日・連休(GW、盆、年末年始)は業種によりCVRが大きく変動する。予約型ビジネスはまとまった休みの直前に駆け込み需要が出やすい。季節性を無視したtCPA未達判断をしない。
- 商材によって客単価が大きく異なる場合(ECの価格帯、保険診療/自由診療の別など)は、CV種別ごとに価値を分けて入れる(拡張コンバージョン値)。

## 3. Performance Max の扱い

- P-Maxは検索キャンペーンの**補完**として使う。検索単体で目標CPAを達成できていない段階で入れない。
- 導入条件: 月50CV以上、アセット(画像・動画)を日本語で用意できること。海外テンプレの英語混じりアセットはCTRを落とす。
- ブランド除外リストを必ず設定(P-Maxがブランド指名を食う問題の防止)。
- 検索テーマ・アセットグループは「施術・商材単位」で分ける。
- 週次で「P-Max流入分を除いた検索キャンペーンのCPA」を確認し、共食いを監視する。

## 4. 週次・月次の運用ルーチン

**週次(15分)**
1. 検索語句レポート確認 → 除外KW追加(`negative-keyword-scanner` に委譲)
2. 予算消化ペース確認(月中で消化率が日割り±15%超ならアラート)
3. CV急減チェック: タグ落ち・LP障害・電話計測切れをまず疑う

**月次**
1. KW別・広告グループ別のCPA/CVR推移(前月比・前年同月比)
2. オークションインサイトで競合の動き(日本は少数競合の入札強化が単価に直結しやすい)
3. RSAアセット評価「低」の差し替え(`rsa-copywriter-ja` に委譲)
4. クライアント向け月次報告(`client-report-generator-ja` に委譲)

## 5. 規制業種コンプライアンス(日本固有・最重要)

### 医療広告(歯科含む)
- **医療広告ガイドライン**(医療法)が広告表現を規制。リスティング広告・LPも「広告」に該当する。
- 禁止: 比較優良広告(「地域No.1」「最高の技術」)、誇大広告、**治療効果に関する患者の体験談**、誤認しうるビフォーアフター写真。
- 自由診療(インプラント・矯正・ホワイトニング等)は**限定解除要件(4要件)**を満たせば広告可能事項を拡大できる: ①患者が自ら求めて入手する情報(ウェブサイト・LP等)であること ②問い合わせ先の明記 ③自由診療の治療内容・費用の明記 ④リスク・副作用の明記。LPに②③④が揃っているか必ず確認する。
- **限定解除が適用されるのはウェブサイト・LP側のみ**。検索広告の広告文やバナーそのもの(プッシュ型)は①を満たさないため、広告文には広告可能事項の範囲内の表現しか書けない(専門外来名・詳細な効果訴求は広告文に載せない)。
- Google側ポリシー: ヘルスケア関連は事前認証が必要なカテゴリあり。リマーケティング(パーソナライズド広告)は医療系で制限される。

### その他
- 薬機法: 化粧品・健康食品・医療機器の効能表現に制限。「シミが消える」等はNG。
- 景品表示法: 優良誤認・有利誤認。「最安値」「業界初」は客観的根拠資料が必要。二重価格表示は直近8週間の販売実績が目安。打消し表示は本文と同等の視認性が必要。
- 特定商取引法: EC・定期購入は最終確認画面の表示義務。定期縛りの誤認防止。

**広告文・LPを提案する際は、該当業種ならこの章のチェックを通してから出力すること。** 疑わしい表現は代替案を併記する。

## 6. 実行と記録(分析で止めない)

運用判断は**実行されて初めて完了**。`management/pdca-runner-ja` の台帳(`docs/pdca/広告運用.md`)で回す:

- **実行手段**: Google Ads API/MCP接続があれば変更を直接実行。なければ管理画面の操作手順書+変更内容CSVを納品し「手動実行待ち」と記録
- **承認ゲート**(pdca-runnerの初期ルール): 除外KW追加・レポート生成は自動実行可。**予算増額・入札戦略変更・配信開始/停止は承認必須**(承認依頼に「変更内容/根拠数値/巻き戻し方法」を添えて停止)
- **変更ログ**: 実行した変更は日付・対象・変更前後の値を台帳に記録(Google広告の変更履歴と突合できる粒度で)
- **翌週の検証**: 変更に対して§2の学習期間を踏まえた判定日を設定し、その日のサイクルで効果判定→次の一手へ

## 7. 出力様式

分析結果は以下の順で出す:
1. **結論**(やる/やらない/様子見 と理由を1〜2文)
2. 根拠データ(表形式、円・%)
3. 実行計画(実行手段・承認要否・判定日)
4. リスクと巻き戻し方法
