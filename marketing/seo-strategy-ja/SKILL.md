# 日本市場SEO戦略スキル

サイト全体のSEOを診断し、優先順位付きの施策ロードマップを作る。個別作業は下位スキルに委譲する:
- 記事の採点・添削 → `seo-content-scorer-ja`
- 順位・SERP・競合調査 → `seo-research-ja`
- 文体仕上げ → `ja-humanizer`

## 日本市場の前提

- Yahoo! JAPANはGoogleの検索エンジンを採用しているため、**Google対策=国内シェア9割超をカバー**。Bing(1桁%)は原則後回し。
- モバイル比率が高く(多くの業種で7〜8割)、モバイル表示・速度を優先。
- 日本語KWは**表記ゆれ**(漢字/ひらがな/カタカナ、送り仮名、長音)で検索ボリュームが分散する。KW調査時は主要表記を合算して評価する。
- ローカルビジネス(店舗・サロン・クリニック等)は通常のSEOより**Googleビジネスプロフィール(MEO)**の優先度が高い。「地域名+業種」検索はローカルパックが最上部を占有するため、戦略にMEOを必ず含める。
- YMYL(医療・金融・法律)はE-E-A-Tの要求水準が特に高い。医療は有資格者監修なしの記事量産は逆効果。

## 診断→施策の4フェーズ(この順で。土台を飛ばさない)

### Phase 1: Technical SEO(土台)
チェック項目:
- インデックス状況(site:検索、Search Consoleのカバレッジ)
- クロール阻害: robots.txt、noindexの誤設定、canonicalの誤り
- Core Web Vitals(特にモバイルLCP)
- 構造化データ: ローカルビジネスは `LocalBusiness`(業種別サブタイプがあればそれ)、記事は `Article`、FAQは `FAQPage`
- スマホ表示、SSL、404/リダイレクトチェーン
- **日本語URL**: 日本語スラッグは共有時に percent-encoding で壊れやすい。新規は英数字スラッグを推奨(既存の日本語URLの一括変更はリスクが上回るため非推奨)

### Phase 2: On-Page(既存ページの改善)
- 主要ページのtitle/meta/hタグ最適化(title全角32文字、description全角120文字目安)
- 検索意図とページタイプの不一致検出(記事で獲るべきKWをLPで狙っていないか、逆も)
- カニバリゼーション検出: 同一KWで複数ページが競合していないか
- 内部リンク構造: 収益ページ(予約・問い合わせ)への導線設計

### Phase 3: Content(新規制作)
- KWマップ作成: 「地域×サービス」「悩み×解決策」「比較・vs」などの軸でKWを意図別に分類し、既存ページに割当て→空白がコンテンツギャップ
- 優先順位 = (検索ボリューム × CV距離 × 競合の弱さ) で採点。**CVに近いKWから作る**(「◯◯ 費用 相場」>「◯◯とは」)
- 制作した記事は `seo-content-scorer-ja` で採点してから公開
- 医療コンテンツは限定解除要件・監修体制をコンテンツ計画に組み込む

### Phase 4: Off-Page
- 日本で現実的な被リンク獲得: 地域メディア・商工会議所・提携先・取材(プレスリリース経由)、業界団体名簿
- サイテーション: NAP情報(名称・住所・電話)の表記統一(全角半角・ビル名の有無まで揃える)
- 口コミ戦略(MEO連動): 依頼導線の設計 ※**口コミへの謝礼・インセンティブは医療機関では違反**(景表法ステマ規制・Googleポリシー・医療広告ガイドライン)

## 出力フォーマット

```
## 現状診断サマリ
(3〜5行。最大のボトルネックがどのフェーズにあるか)

## 施策ロードマップ
| 優先度 | フェーズ | 施策 | 期待効果 | 工数目安 | 担当スキル/人 |

## 今月やること(3件以内)
(具体的な作業指示レベルまで分解)

## 測定方法
(何を・どのツールで・どの頻度で見るか)
```

## 原則

- 施策は常に「効果×工数」で優先順位を付け、一度に3件以上を「今月やること」に入れない。
- アルゴリズム更新の憶測で戦略を変えない。順位変動時はまず技術要因(インデックス・タグ)を疑う。
- 「記事を月N本」というノルマ型の提案をしない。KWマップの空白を埋める必然性ベースで本数を決める。
