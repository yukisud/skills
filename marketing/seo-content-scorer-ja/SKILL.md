# 日本語SEO記事採点スキル

記事ドラフトを受け取り、100点満点で採点して具体的な修正指示を返す。対象KWが未指定なら記事から推定し、推定である旨を明記する。

## 採点基準(100点)

### 1. キーワード配置(25点)
- [ ] titleに対象KWが前方寄りで入っている(全角32文字以内目安、超過分は検索結果で省略) — 5点
- [ ] h1にKWが自然に入っている — 3点
- [ ] 導入文(最初の150文字)にKWと検索意図への回答がある — 5点
- [ ] h2の30〜50%にKWまたは関連語が入っている(全h2に機械的に入れるのは減点) — 5点
- [ ] meta description(全角120文字目安)にKWと行動喚起がある — 3点
- [ ] **表記ゆれの統一**: KWの表記(カタカナ/ひらがな/漢字、長音有無)が記事内で統一されている — 4点

### 2. 見出し構造(20点)
- [ ] h2→h3の階層が正しい(h2の下にh4が直接来ない、h3が単独1個で終わらない) — 5点
- [ ] 見出しだけ読んで記事の結論と流れがわかる — 5点
- [ ] 検索意図の主要サブトピックを網羅(競合上位のh2と突合できる場合は突合) — 5点
- [ ] 結論先出し(PREP)。日本語記事にありがちな「そもそも〜とは」から始まる構成は、指名・比較系KWでは減点 — 5点

### 3. 検索意図とコンテンツ品質(25点)
- [ ] Know/Do/Buy/Goの意図分類と記事タイプ(解説/比較/事例/LP)が一致 — 5点
- [ ] 共起語・関連語が自然に含まれる(サジェスト・再検索KWのカバー) — 5点
- [ ] 独自性: 一次情報(自社データ・症例・事例・体験)があるか。他記事の要約だけなら大幅減点 — 10点
- [ ] 具体性: 数字・手順・図表の指定があるか — 5点

### 4. E-E-A-T(20点) — YMYL(医療・金融・法律)は配点2倍で40点、その分1〜3を圧縮
- [ ] 著者・監修者情報(医療なら有資格者の監修表記) — 5点
- [ ] 出典: 公的機関・学会・論文へのリンク(医療なら厚労省・学会ガイドライン) — 5点
- [ ] 情報の鮮度: 更新日・データの年次明記 — 5点
- [ ] **医療広告ガイドライン適合**: 効果保証・体験談・ビフォーアフターの不適切使用がない(クリニックサイト内の記事は広告規制対象になりうる) — 5点

### 5. 内部リンク・導線(10点)
- [ ] 関連記事への内部リンクが本文中に2本以上、アンカーテキストがリンク先の内容を表す(「こちら」はNG) — 5点
- [ ] CV導線: 記事の目的に応じたCTA(予約・問い合わせ・資料DL)が適切な位置にある — 5点

## 日本語ライティング減点チェック

以下は各▲1〜3点の減点方式:
- 文体不統一(です・ます調とだ・である調の混在)
- 一文が長すぎる(100文字超の文が頻出)
- 同一文末の3連続(「〜です。〜です。〜です。」)
- 冗長表現(「することができます」「という形になります」)
- 漢字の開きすぎ/閉じすぎの不統一(「事」「時」「〜して下さい」)
- 半角/全角の混在(英数字は半角統一を推奨)

## 出力フォーマット

```
## 総合スコア: XX / 100

| 項目 | 得点 | 満点 |
|---|---|---|

## 重要な修正(スコアに大きく影響する順)
1. (箇所の引用 → 修正案)

## 軽微な修正
(箇条書き)

## このままで良い点
(2〜3点。何が機能しているかを明示)
```

修正指示は必ず「どこを」「どう直すか」の対で書く。抽象的な指摘(「もっと具体的に」)だけで終わらせない。再提出されたら差分を再採点する。
