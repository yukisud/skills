# プレスリリース作成スキル(日本仕様)

「会社が言いたいこと」ではなく「記者が記事にできる事実」を書く。指名検索・被リンクの起点としてGTM(`gtm/gtm-strategy-ja`)のチャネルの一つに位置づける。

## 0. 配信判断(書く前に)

ニュース価値が1つもなければ配信しない(スパム配信は媒体との関係を毀損する):
- **新規性**: 初/最大/独自(客観的根拠必須。景表法は広告と同基準)
- **社会性・時事性**: 社会課題・季節・トレンドとの接続
- **意外性**: 常識との逆転、異業種コラボ
- **地域性**: 地方メディアは「地元企業の」だけで価値になる
- **データ**: 独自調査の数字はそれ自体がニュース(調査リリースは掲載されやすい定番)

弱い場合は「調査リリース化」(自社データ・アンケートを主役に)を提案する。

## 1. 構成(逆三角形・記者がコピペで記事にできる形)

```
1. タイトル: 全角30字前後。事実+新規性+数字(「◯◯を提供開始」だけで終わらせない)
2. サブタイトル: 補足の事実1つ
3. リード: 5W1Hを3〜4行で完結(ここだけで記事が書ける状態に)
4. 本文: 背景(社会・市場の文脈)→内容の詳細→今後の展開
5. 代表・担当者コメント(人格のある言葉で。定型の「嬉しく思います」を避ける)
6. 画像: メイン1枚+補足(記事に使える横長・高解像度・権利クリア)
7. サービス概要・会社概要・本件の問い合わせ先(広報連絡先は必須)
```

- 一人称は「当社」、文体はです・ます。形容詞でなく数字と事実(`ja-humanizer` の原則を適用)
- 専門用語は初出で説明。記者は業界人ではない前提
- **未確定・希望的観測を事実のように書かない**。「予定」「見込み」を明記

## 2. 配信・アプローチ

- 配信タイミング: 平日午前(10〜11時)が基本。金曜午後・連休前は埋もれる。他社の大型発表・大きな事件の日は避ける
- 配信サービス(PR TIMES等)+**個別アプローチの二段構え**: 相性の良い媒体・記者を3〜5選び、「なぜ貴媒体の読者に関係あるか」を1〜2行添えて個別送付(一斉BCCの売り込みはしない)
- 地方企業は地元紙・地域経済誌・自治体広報との関係構築が全国媒体より費用対効果が高い
- 解禁日時(エンバーゴ)がある場合は明記。上場企業・上場企業との協業は適時開示・インサイダー情報の扱いを先に確認

## 3. 法令・リスクチェック

- [ ] 「No.1」「初」の根拠資料(調査主体・範囲・時期)があるか
- [ ] 薬機法・医療広告・金融など規制業種の表現(リリースも広告規制の対象になりうる)
- [ ] 他社名・提携先を出す場合、**先方の広報承認を取ったか**(無断言及は関係事故の定番)
- [ ] 写真・ロゴ・人物の権利と掲載許可
- [ ] 調査リリースの場合、調査概要(n・手法・期間)を明記したか

## 納品物の様式

リリース作成の依頼には3点セットで納品する:
1. **リリース本文**(§1の構成どおりの完成形。タイトルは3案)
2. **配信計画**(配信日・時間帯・配信サービス・個別アプローチ先3〜5媒体とその選定理由)
3. **チェック結果**(§3の法令・リスクチェックの通過状況。未確認事項は明記)

## 4. 効果測定と資産化

- 測る: 掲載数(転載除く)、指名検索の増分(`data-science/sc-ga4-report-ja`)、被リンク(`marketing/seo-strategy-ja` Phase4)、問い合わせ・採用応募への波及
- 掲載実績はLP・営業資料の信頼要素に転用(「◯◯掲載」はロゴ使用条件を媒体に確認)
- 記者の反応(開封・返信)を記録し、次回のアプローチリストを更新する
