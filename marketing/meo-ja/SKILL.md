# MEO運用スキル(Googleビジネスプロフィール)

「地域名+業種」検索の最上部を占めるローカルパック/マップでの露出を最大化する。歯科医院などの来店・予約型では通常のSEO(`marketing/seo-strategy-ja`)より優先度が高いことが多い。

## ローカル検索順位の3要因と打ち手の対応

| 要因 | 意味 | 主な打ち手 |
|---|---|---|
| 関連性 | 検索語とプロフィールの一致 | カテゴリ設定・サービス登録・説明文・投稿 |
| 距離 | 検索地点からの近さ | 操作不能。**商圏の現実を受け入れて計画する**(駅前競合に距離で勝てない立地の場合、指名・口コミ・SEO側に比重を移す) |
| 視認性(知名度) | 口コミ・サイテーション・Web上の言及 | 口コミ獲得運用、NAP統一、被リンク(`seo-strategy-ja` Phase4と連動) |

## 1. プロフィール整備(初期セットアップ/監査)

- [ ] **メインカテゴリ**が最重要(歯科なら「歯科医院」。矯正中心なら「矯正歯科医」をメインにする判断も)。追加カテゴリは提供サービスの範囲で全部
- [ ] ビジネス名は**正式名称のみ**。「◯◯歯科|渋谷の無痛インプラント」のようなキーワード追加は**ガイドライン違反**(修正指示・停止リスク)。競合がやっていても追随しない(違反報告は可能)
- [ ] NAP(名称・住所・電話)を公式サイト・ポータル・SNSと**一字一句レベルで統一**(ビル名有無・全角半角・ハイフン)
- [ ] 営業時間(祝日・臨時休業を含めて常に最新)、属性(バリアフリー・駐車場等)、予約リンク(予約システムのURL)
- [ ] サービス/メニュー登録: 施術ごとに説明と価格帯(医療の価格表示は限定解除の考え方に準じ、総額の目安と変動条件を書く)
- [ ] 写真: 外観(入口がわかる)・内観・設備・スタッフを各複数枚。**外観写真は「初めて行く人が迷わないか」基準**。ストック写真の流用はしない
- [ ] ウェブサイトリンクにUTMパラメータを付け、GA4でMEO経由流入を分離計測(`data-science/ga4-analysis-ja`)

## 2. 口コミ運用(視認性の中核)

### 獲得
- 依頼の導線を設計する: 会計時・治療完了時の声かけ+QRコード(レビューリンクの短縮URL)。**依頼するタイミングは満足が最大化した瞬間**(治療完了・悩み解消時)
- **謝礼・割引と引き換えの口コミ依頼は不可**(Googleポリシー違反+ステマ規制。医療は医療広告ガイドライン上もアウト)。「よろしければ」の依頼までにする
- 良い体験をした人に一様に依頼する(選別依頼=レビューゲーティングもポリシー違反)

### 返信(全件・48時間以内目安)
- 高評価: 感謝+来院内容に軽く触れる(個人の特定・診療内容の詳細暴露はしない)
- 低評価: 感謝→受け止め→事実確認の姿勢→オフライン窓口の提示。**反論・言い訳・患者情報の開示は絶対にしない**(守秘義務。「カルテ上は〜」等は重大違反)
- 医療機関の返信では治療効果の約束・宣伝的な誘導をしない(返信も広告的表現とみなされるリスク)
- 事実無根・誹謗中傷の口コミ: 返信で冷静に事実誤認の可能性を示しつつ、Googleへの削除申請(ポリシー違反報告)を並行する。削除は通らないことが多い前提で、**良い口コミの量で希釈する**のが本線

## 3. 継続運用(週次/月次)

**週次**: 新規口コミへの返信、Q&Aの確認(質問には公式として回答。よくある質問は自分で投稿して回答しておくのが定石)
**月次**:
- 投稿(最新情報・キャンペーン※医療は広告規制の範囲内で)を2〜4本
- 写真の追加(季節・新設備)
- インサイト確認: 検索語句(直接/間接)、表示回数、経路検索・電話・サイトクリック数の前月比
- 順位計測: 主要KW×複数地点で確認(**順位は検索地点で変わる**。院の前だけで測って安心しない。商圏の端の地点でも測る)

## 4. サイテーション・外部整備

- 主要ポータル(歯科なら病院検索系)・地図サービス・SNSプロフィールのNAP統一棚卸し(四半期に一度)
- 公式サイト側に構造化データ(`Dentist`/`LocalBusiness`)、アクセスページの充実(`engineering/frontend-design-ja`・`marketing/seo-strategy-ja` と連動)

## 原則

- 順位の日次変動に一喜一憂しない。追うのは**電話・経路検索・予約の実数**。
- ガイドライン違反の裏技(ビジネス名KW詰め、自作自演口コミ、大量のダミー地点登録)は提案しない。停止されたら回復に数週間〜数ヶ月かかり、失うものが大きすぎる。
