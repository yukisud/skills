# 価格戦略スキル(日本市場)

「原価+相場」の思考停止を避け、価値と検証に基づいた価格を設計する。GTM計画(`gtm/gtm-strategy-ja`)のKPIツリーと、競合価格調査(`gtm/competitor-analysis-ja`)を入力にする。

## 1. 価格決定の3つの根拠(全部を見る)

1. **価値基準**(上限): 顧客が得る価値の金額換算(削減コスト・増加売上・代替手段の総コスト)。BtoBは「導入しない場合に払い続けるコスト」を試算して価格の錨にする
2. **競合基準**(相場帯): 競合分析の価格マップ。**同じ価格帯に置くなら差別化根拠、外すなら理由の説明力**が必要
3. **コスト基準**(下限): 粗利構造。値引き・広告費・決済手数料込みで単位経済が成立する下限を先に確定する

- 日本市場の傾向として価格感度が高く「理由のない高価格」への抵抗が強い一方、**「安すぎる」ことも品質不安を招く**(特に医療・BtoB)。相場から外す場合は上下どちらでも理由をコピーで語れるようにする。

## 2. プラン設計(松竹梅)

- 3案構成が日本では最も通りやすい: 松(全部入り・アンカー)/**竹(売りたい本命)**/梅(入口・比較用)。多くの顧客は真ん中を選ぶ。
- 設計ルール:
  - 竹に主要価値を全部入れる。梅は「竹にしておけばよかった」と思う欠落を1つだけ作る(意地悪な骨抜きにしない)
  - 4プラン以上は選択疲れで離脱を生む。オプションは本体プランと分離して後出しする
  - プラン名は機能名でなく顧客の状態名に(「スタンダード」より「開業medium向け」のような自分ごと化)※媒体・トンマナによる
- 端数価格(9,800円/98,000円)は刈り取り・BtoCで有効。高級・信頼路線(自由診療の高額治療等)はキリの良い価格+内訳明示の方が信頼を得やすい。
- サブスク・定期: 年払い割引は2ヶ月分無料相当(約17%)が通りやすい相場。**定期縛りは特商法の最終確認画面表示義務**(回数条件・総額・解約方法)を必ず設計に含める。

## 3. 価格調査の方法

- **PSM分析**(価格感度測定): 「高すぎる/高い/安い/安すぎる」の4問アンケートで受容価格帯を推定。n=50以上で参考値になる
- 実売テスト: LP・広告で価格違いのオファーをテストするのが最も信頼できる(ただし既存客に見える形での価格差テストは信頼毀損リスク。対象を分離する)
- 商談での反応記録: 「高い」と言われた件数より、**価格を理由に失注した率**を記録する(値引き要求と支払不能は別物)

## 4. 値上げの進め方(日本仕様)

値上げは日本では特に感情的な抵抗が大きい。手順を踏む:

1. **新規から先に値上げ**し、成約率への影響を実測する
2. 既存客は据え置き期間を設けて事前通知(1〜3ヶ月前)。通知文には理由(品質維持・原材料・機能追加)を具体的に書く。「諸般の事情」は不信を招く
3. 値上げと同時に**何かを足す**(サポート枠・機能・特典)と受容率が大きく上がる
4. 解約・離反の許容ラインを事前に決める(値上げ幅×残存率で増収になる損益分岐)

## 5. 価格表示の法令(必須チェック)

- [ ] **総額表示義務**: 消費者向け価格は税込総額が明瞭に表示されていれば可(「11,000円」「11,000円(税込)」「10,000円(税込11,000円)」はいずれも可)。**不可なのは税込総額のない表示**(「10,000円(税抜)」「10,000円+税」)
- [ ] **二重価格表示**: 「通常価格◯円→今だけ◯円」は通常価格での相当期間の販売実績(直近8週間のうち過半が目安)が必要。架空の元値は有利誤認
- [ ] 「最安値」「地域最安」は根拠と調査時点が必要(景表法)
- [ ] 医療(自由診療): 価格を広告に出す場合は限定解除要件とセット。「◯円〜」の下限表示は総額との乖離が大きいと誇大広告リスク。**総額(検査・調整料込み)の明示が信頼にも直結**
- [ ] 定期・サブスク: 特商法の最終確認画面(総額・期間・解約条件)
