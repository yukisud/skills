# 競合分析スキル(日本市場)

「調べて表にして終わり」の競合分析を禁止し、**自社の意思決定(ポジショニング・価格・チャネル)に接続する差分**だけを抽出する。SEO面の競合監視は `data-science/seo-research-ja`、分析結果の受け手は `gtm/positioning-messaging-ja` と `gtm/pricing-strategy-ja`。

## 0. 分析の設計(最初に決める)

- **意思決定の明確化**: この分析で何を決めるのか(参入判断/訴求の差別化/価格改定/広告出稿判断)。決めることが無い調査は始めない。
- **競合の3分類**: ①直接競合(同商圏・同業) ②検索競合(狙いKWで上位のサイト・ポータル) ③代替手段(何もしない・自力・別カテゴリ)。ローカルビジネスは商圏内の直接競合を5社まで、それ以外は各2〜3に絞る。

## 1. 日本で使える情報源と調べ方

| 調べる対象 | 情報源 | 見るポイント |
|---|---|---|
| 訴求・メッセージ | 公式サイト・LP | FVのキャッチ、選ばれる理由、証拠の種類(数字/資格/事例) |
| 広告出稿 | **Google広告の透明性センター、Meta広告ライブラリ** | 出稿有無・クリエイティブの訴求軸・継続出稿されている広告(=当たっている可能性が高い) |
| 検索面 | 指名検索・狙いKWのSERP、OpenSEO(`data-science/openseo-ja`)の競合流入KW推定 | 指名KWに競合が入札しているか、ポータル依存度、どのKW群で流入を取っているか |
| 価格 | 料金ページ・ポータル掲載価格 | 価格帯、税込/税抜、松竹梅構成、非公開(要見積)か |
| 評判 | Googleマップ口コミ・SNS・比較サイト | **低評価口コミは競合の弱み=自社の差別化仮説の宝庫**。星の数より本文を読む |
| 体制・規模 | 会社概要、採用ページ、登記情報(国税庁法人番号公表サイト)、上場企業ならIR・決算説明資料 | 従業員数・拠点・注力領域(採用職種は戦略の先行指標) |
| 新着動向 | プレスリリース(PR TIMES等)、サイト更新 | 新サービス・提携・値上げ |
| ローカル(店舗・クリニック等) | Googleビジネスプロフィール | 口コミ数と返信品質、写真の質、投稿頻度、掲載カテゴリ |

- 取得はすべて公開情報の範囲で行う。ログインが必要な会員情報の共有・スクレイピング規約違反はしない。
- 覆面調査(問い合わせ・資料請求)を行う場合は依頼者に確認してから。

## 2. 分析フレーム

### 訴求マップ(ポジショニング接続用)
各社のFVキャッチ・選ばれる理由を並べ、**訴求軸の空白地帯**を探す(全社が「技術」を訴求→「通いやすさ」が空く等)。空白は「誰も言っていない」だけで「顧客が求めていない」可能性もあるため、口コミ・検索クエリで需要の裏取りをする。

### 4P比較表
| 項目 | 自社 | 競合A | 競合B |
(Product: 提供範囲・品質の証拠 / Price: 価格・支払方法 / Place: 商圏・チャネル / Promotion: 広告・SEO・SNS・ポータル)

### 強弱の判定ルール
- 「強い/弱い」は主観でなく観察事実に紐付ける(「口コミ4.8×320件」「指名検索で広告+自然1位を独占」)。
- 確認できなかった項目は空欄のまま「不明」と書く。**埋めるための推測をしない。**

## 3. 打ち手への接続(必須の締め)

```
## 競合分析サマリ: (対象市場)(YYYY/MM時点)
### 結論(3行)
(市場の構図と、自社が取るべきポジションの提案)

### 自社への示唆
| 発見 | 根拠 | 提案する打ち手 | 引き継ぎ先 |
(例: 全社が体験談型LP→医療広告GL違反リスクを彼らは負っている。自社は適法な症例数訴求で信頼側に立つ → positioning-messaging-ja へ)

### 監視リスト
(継続監視する競合×項目×頻度。月次はseo-research-jaの週次ブリーフィングに統合)
```

## 4. 原則

- 競合の真似を打ち手にしない(相手の当たり施策は相手の文脈で当たっている)。差分と空白から打ち手を作る。
- 分析は日付を付けて `docs/competitor/` に保存し、四半期ごとに差分更新する(毎回ゼロから調べ直さない)。
- 競合を貶める表現をアウトプット(広告・LP・営業資料)に持ち込まない。比較広告は日本では法的・文化的リスクが高い。
