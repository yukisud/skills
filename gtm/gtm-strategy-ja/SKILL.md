# 日本市場GTM戦略スキル

新サービス・新商品・新規事業の市場投入計画を作る司令塔。ここで決めたメッセージとチャネルを下位スキルに展開する:
- LP → `creative/lp-builder-ja` / 広告文 → `marketing/rsa-copywriter-ja` / クリエイティブ → `creative/ad-creative-ja`
- リード管理・ナーチャリング → `marketing/hubspot-ops-ja` / 営業資料 → `creative/sales-deck-ja`
- 検索流入 → `marketing/seo-strategy-ja` / 広告運用 → `marketing/google-ads-ja-ops`

## 1. 前提の言語化(ここを飛ばして施策に入らない)

- **誰の・どんな状況の・何を解決するか**(セグメント→ターゲット→ポジショニング)。「30代女性」のようなデモグラだけのターゲット定義は却下し、状況・トリガー(JTBD)まで掘る。
- **バリュープロポジション1文**: 「(誰)が(状況)のとき、(競合・代替手段)ではなく自社を選ぶ理由は(差別化要素)だから」。以降の全コピー・全資料はこの1文から派生させ、チャネルごとに勝手なメッセージを作らない。
- **勝ち筋の型の判定**: セールス主導(BtoB高単価)/ マーケ主導(リード獲得→商談)/ プロダクト主導(セルフサーブ)/ 来店・予約型(ローカル)。型によってチャネルとKPIの標準形が変わる。

## 2. 日本市場のチャネル選定マップ

| チャネル | 向いている型 | 日本固有の注意 |
|---|---|---|
| Google検索広告 | 顕在需要がある全型 | 検索ボリュームの事前確認。ニッチBtoBは指名+比較KWのみで十分なことが多い |
| Meta/Instagram広告 | BtoC・来店型・EC | 潜在層向け。クリエイティブ消耗が速い(2〜4週で差し替え前提) |
| LINE | BtoC・来店予約型 | **日本ではメールよりLINE公式アカウントが再来店・リピート導線の主力**。友だち追加をCVポイントに設計 |
| Yahoo!広告 | 高年齢層・地方 | Googleと同じKW資産を流用可。ディスプレイ(YDA)はニュース面で年齢層高め |
| 業界ポータル | 医療・不動産・人材・飲食 | SEOで勝てない領域の実質的な必須枠。掲載費を広告予算として計上 |
| 展示会・セミナー | BtoB | 日本のBtoBは依然オフライン比重が高い。名刺→CRM取込→ナーチャリングの導線を事前設計(hubspot-ops-jaへ) |
| プレスリリース | 新規性のある商材 | PR TIMES等。被リンク・指名検索の起点として設計 |

- チャネルは**最初は2つまで**に絞る。「全部やる」計画は全部が中途半端になるため却下する。
- 各チャネルに「検証する仮説」と「撤退基準」(期間×CPA上限)を必ず付ける。

## 3. ローンチ計画のフォーマット

```
## GTM計画: (サービス名)
### ポジショニング
- ターゲット(状況ベース) / バリュープロポジション1文 / 価格(税込表示) / 競合・代替手段

### フェーズ計画
| フェーズ | 期間 | 目的 | チャネル | 予算 | 成功基準 | 撤退基準 |
(例: Phase1 検証(1〜2ヶ月・少額) → Phase2 拡大 → Phase3 定常運用)

### KPIツリー
売上目標 ← 成約数 × 単価 ← 商談数 × 成約率 ← リード数 × 商談化率 ← 流入 × CVR
(各段に現実的な率を仮置きし、必要流入数を逆算。仮置きの根拠を明記)

### 制作物リスト(担当スキルへの発注書)
| 制作物 | 担当スキル | 期日 | 依存関係 |

### 法令・規制チェック
(業種に応じて: 医療広告GL/薬機法/景表法/特商法/特定電子メール法 — 該当項目と対応)
```

## 4. 原則

- 効果試算は必ず「前提を変えたら結論がどう変わるか」を1行添える(CVR仮置き0.5%→1.0%で必要予算半減、等)。
- ローンチ前にCV計測(タグ・電話・フォーム)の設計を制作物リストに含める。計測なしのローンチを許さない。
- Phase1の検証で得たCVR・CPA実測値でKPIツリーを更新してからPhase2の予算を確定する。初期計画の数字を更新せずに拡大しない。
